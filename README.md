# 📷 مشروع عدسة (3adsa)

تطبيق **عدسة (3adsa)** هو تطبيق ويب حديث مصمم باستخدام **React** و **Vite** لتوفير تجربة مستخدم واجهة وسريعة للتصفح والتفاعل مع المحتوى البصري.

---

## 🚀 المميزات الرئيسية (Features)

- ⚡ **أداء فائق وسريع:** تحزيم وبناء التطبيق باستعمال Vite لضمان تجربة تطوير وتشغيل فائقة السرعة.
- 🎨 **واجهة وتصميم عصري:** الاعتماد على **Tailwind CSS** لبناء واجهات تفاعلية ومتجاوبة (Responsive) مع جميع الشاشات.
- 🧩 **أيقونات متكاملة:** استخدام **FontAwesome Icons** لتقديم أيقونات غنية وتجربة بصريّة متناسقة.
- 🧹 **جودة كود عالية:** ضبط وإعداد **ESLint** تلقائياً للحفاظ على نظافة واتساق الكود.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Front-end Library:** [React.js](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [FontAwesome Free Icons](https://fontawesome.com/) (`@fortawesome/free-brands-svg-icons`, `@fortawesome/free-regular-svg-icons`)
- **Code Quality & Linting:** [ESLint](https://eslint.org/)
